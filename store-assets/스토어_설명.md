# Chrome 웹스토어 등록 정보 (업데이트안)

## 이름 (최대 75자)
Playbook - 녹화로 끝나는 업무 매뉴얼

## 요약 설명 (최대 132자)
클릭 한 번 녹화로 끝나는 업무 매뉴얼. 클릭과 입력을 화면과 함께 기록하고, AI가 단계별 설명까지 써 드려요.

## 상세 설명
당신의 업무가 Playbook이 되는 순간.

업무 매뉴얼, 만들 때마다 캡처하고 붙여넣고 설명 쓰느라 일이 하나 더 생기지 않으셨나요?
Playbook은 평소처럼 일하는 모습을 녹화하는 것만으로 매뉴얼을 완성해요. 따로 정리할 필요 없이, 한 번 해 본 업무가 그대로 팀의 매뉴얼이 돼요.

■ 녹화 한 번이면 매뉴얼 완성
· [녹화 시작]을 누르고 평소처럼 일하세요. 클릭하고 입력한 순서가 화면과 함께 자동으로 기록돼요.
· 녹화를 마치면 AI가 단계마다 제목과 설명을 써서 바로 읽을 수 있는 매뉴얼로 정리해요.
· 캡처하고, 화살표 긋고, 설명을 붙이던 시간이 사라져요.

■ 다듬고, 가리고, 바로 공유
· 단계 순서를 바꾸거나 설명을 고치는 건 문서 고치듯 간단해요.
· 개인정보나 내부 정보가 보이는 부분은 가린 뒤 공유할 수 있어요.
· 완성한 매뉴얼은 링크 하나로 전하거나 PDF로 저장해요.
· 만든 매뉴얼은 한곳에 모여 언제든 다시 찾아볼 수 있어요.

■ 이런 분께 좋아요
· 새로 온 동료에게 같은 설명을 반복하는 분
· 업무 인수인계 문서를 급하게 만들어야 하는 분
· 고객이나 다른 부서에 사용 방법을 안내해야 하는 분

■ 녹화한 업무를 제안 장표로 (Use Case PPT)
HANCOM Agentic OS 제안용으로, 녹화 화면을 Agent 적용 사례 장표로 바꿔 줘요.
· 미팅 정리본(대상·배경·Pain point·목적)만 붙여넣으면 1분 안팎으로 장표가 완성돼요.
· Use Case 요약, Agent 작동 흐름, 실제 적용 화면, 기대 성과까지 한 번에 담아요.
· 기대 성과는 공공기관 공개 자료를 근거로 보수적으로 계산하고, 출처를 함께 적어요.

■ 시작하는 방법
1. 확장 프로그램을 설치하고 Playbook에 로그인하세요.
2. [녹화 시작]을 누르고 평소처럼 업무를 진행하세요.
3. 녹화를 마치면 매뉴얼이 만들어져요. 자세한 사용법은 웹의 [사용 방법]에서 볼 수 있어요.

## 이번 업데이트에서 바뀐 점
· 웹 화면 전체 디자인 개편, 홈 시작 화면과 사용 방법 안내 추가
· 에이전틱OS 시연 녹화 시 Tab 이동 단계까지 캡처
· HANCOM Agentic OS 도입 제안 장표(Use Case PPT) 만들기 추가
