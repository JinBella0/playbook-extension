# Chrome 웹스토어 등록 정보 (업데이트안)

## 이름 (최대 75자)
Playbook - 녹화로 끝나는 업무 매뉴얼

## 요약 설명 (최대 132자)
클릭 한 번 녹화로 끝나는 업무 매뉴얼. 클릭과 입력을 화면과 함께 기록하고, AI가 단계별 설명까지 써 드려요.

## 상세 설명
당신의 업무가 Playbook이 되는 순간.
평소처럼 일하면서 녹화만 켜 두세요. 클릭한 화면과 입력한 내용이 순서대로 기록되고, AI가 단계마다 제목과 설명을 써서 업무 매뉴얼을 만들어 드려요.

■ 녹화 매뉴얼
· 확장 프로그램에서 [녹화 시작]을 누르고 평소처럼 업무를 진행해요.
· 클릭과 입력한 단계가 화면과 함께 자동으로 저장돼요.
· AI가 단계마다 제목과 설명을 써서 한국어 매뉴얼을 만들어요.
· 단계 순서와 설명을 고치고, 가릴 부분을 가린 뒤 공유 링크나 PDF로 전할 수 있어요.

■ HANCOM Agentic OS 도입 제안 장표 (Use Case PPT)
HANCOM Agentic OS 고객 제안을 위한 기능이에요.
· 미팅 정리본(대상·배경·Pain point·목적)을 붙여넣으면 1분 정도면 Use Case PPT가 완성돼요.
· Use Case 요약, Agent 작동 흐름, 실제 적용 화면, 기대 성과를 표지·마무리 장과 함께 담아요.
· 기대 성과의 처리 시간은 공공기관 발표 자료를 근거로 보수적으로 산정하고, 출처를 장표에 적어요.

■ 이렇게 시작해요
1. 확장 프로그램을 설치하고 Playbook에 로그인해요.
2. 확장 프로그램의 [녹화 시작]을 눌러 업무를 녹화해요.
3. 자세한 순서는 웹의 [사용 방법] 메뉴에서 볼 수 있어요.

## 이번 업데이트에서 바뀐 점
· 웹 화면 전체 디자인 개편, 홈 시작 화면과 사용 방법 안내 추가
· 에이전틱OS 시연 녹화 시 Tab 이동 단계까지 캡처
